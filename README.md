 # Sentiment Analysis on Product Reviews Using Machine Learning

## Project Overview

This project is a web-based application that analyzes Amazon product reviews and classifies customer sentiments into Positive, Negative, and Neutral categories using Machine Learning and Natural Language Processing (NLP).

## Technologies Used

* Python
* Flask
* MySQL
* HTML
* CSS
* JavaScript
* Hugging Face Transformers
* Apify API
* NLP

## Features

* Amazon Product Review Analysis
* Sentiment Classification
* User Registration and Login
* Analysis History
* Dashboard Analytics
* Customer Feedback Visualization

## Project Modules

* Authentication Module
* Product Review Analysis Module
* Sentiment Prediction Module
* Database Management Module
* Analytics Dashboard
